# Platform 14: Learning & Analytics

## 1. Purpose
Consumes the entire history of evidence, decisions, and execution to run attribution and statistical learning.

## 2. Extension Policy
This policy dictates what can and cannot be modified within this platform.

### Allowed Changes
- Replay Analytics
- Attribution
- Drift Detection
- ML/RL Optimization
- Calibration

### Forbidden Changes
- Mutating Historical Evidence
- Direct live execution routing

## 3. Strict Layer Ownership

### Owns
- Attribution
- Drift Detection
- ML/RL Optimization
- Calibration

### Cannot Own
- Mutating Historical Evidence
- Direct live execution routing
