# Platform 12: Decision Support

## 1. Purpose
Consumes interpretation graphs and produces strategic execution plans, managing conflict and risk.

## 2. Extension Policy
This policy dictates what can and cannot be modified within this platform.

### Allowed Changes
- Decision Feature Extraction
- Methodology Consensus
- Confidence Calibration
- Decision Graph Nodes

### Forbidden Changes
- Direct Market Data access
- Live Order Routing
- Broker Implementations

## 3. Strict Layer Ownership

### Owns
- Decision Vectors
- Execution Candidates
- Conflict Resolution
- Strategic Plans

### Cannot Own
- Order routing
- Broker abstraction
- Evidence extraction
