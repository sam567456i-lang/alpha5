# Platform 11: Methodology Interpretation

## 1. Purpose
Applies methodology profiles (ICT, SMC, Wyckoff) to objective evidence, outputting subjective interpretations.

## 2. Extension Policy
This policy dictates what can and cannot be modified within this platform.

### Allowed Changes
- New Profiles (YAML)
- New Policies
- New Projection Rules
- New Methodology Packages

### Forbidden Changes
- Custom Indicators
- Evidence Mutation
- Decision Making
- Execution Directives

## 3. Strict Layer Ownership

### Owns
- Methodology Profiles
- Subjective Interpretations
- Projections
- Evaluator logic

### Cannot Own
- Objective indicator generation
- Decisions
- Execution logic
