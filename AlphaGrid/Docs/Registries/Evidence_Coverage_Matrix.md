# Evidence Coverage Matrix

This matrix tracks the mapping of specific evidence outputs to the downstream programs that rely on them. It prevents the creation of "orphaned evidence" that costs computation but provides no trading value.

| Evidence Type | Producer (Family) | Consumers (Methodologies/Programs) | Status (CRL) |
|---|---|---|---|
| **FVG** | Imbalance Family | ICT, SMC, Price Action, Decision Engine, Learning, Dashboard | CRL-7 (Certified) |
| **Liquidity Pool** | Liquidity Family | SMC, ICT, Decision Engine, Learning, Dashboard | CRL-7 (Certified) |
| **POC** | Market Profile | AMT, Decision Engine, Analytics | CRL-2 (Specification) |
| **Delta** | Order Flow | Analytics, Decision Engine | CRL-0 (Concept) |
| **Spring Event** | Wyckoff Evidence | Wyckoff Profile, Decision Engine | CRL-1 (Architecture) |
| **Session Highs** | Time Family | ICT, Decision Engine | CRL-7 (Certified) |
