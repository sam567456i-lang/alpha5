# Methodology Certification Matrix

This ledger tracks the certification lifecycle of various methodologies built on top of the Platform 11 interpretation and projection engine.

## Lifecycle States
- **Experimental**: In active development, APIs unstable.
- **Implemented**: Parity achieved, functional.
- **Verified**: Passing all edge-case regressions.
- **Certified**: Compliant with all architectural constitutional guarantees.
- **Frozen**: Locked for production use; no further modifications allowed without a wave upgrade.
- **Deprecated**: Slated for removal.
- **Archived**: Moved to legacy archive.
